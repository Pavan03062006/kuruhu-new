PROJECT OVERVIEW
================================================================================
A premium, production-ready authentication portal with peak glassmorphism design
for the Karnataka State Police featuring dual authentication methods.

================================================================================

EXTRACTION
================================================================================
To extract the archive:

  tar -xzf ksp-login-portal.tar.gz
  cd v0-project

QUICK START (3 Commands)
================================================================================

1. Extract:
   tar -xzf ksp-login-portal.tar.gz && cd v0-project

2. Install:
   pnpm install

3. Run:
   pnpm dev

Then open: http://localhost:3000

KEY FEATURES
================================================================================
✅ Dual Authentication Methods
   - Mobile Number + 6-digit OTP verification
   - Police Service Number (PSN) + 4-digit PIN
   - Real-time mode toggle

✅ Premium Design
   - Peak glassmorphism with multi-layer effects
   - Official KSP emblem display
   - KSP branding watermark background (15% opacity)
   - Responsive desktop and mobile views
   - Smooth animations and transitions

✅ Form Features
   - 29 Karnataka districts selection
   - 3 language support (English, Kannada, Hindi)
   - Terms & Privacy Policy links
   - Blue gradient submit button
   - Form validation and error handling
   - Success confirmation display

✅ Technical
   - Built with Next.js 16 + React 19
   - Tailwind CSS v4 for styling
   - TypeScript for type safety
   - shadcn/ui components
   - Production-ready code
